# シゴト健診（旧：①診断チェッカー）

## v2の仕組み（9/28改訂版）

1. 業種を選ぶ（14業種、[task-lists/](task-lists/)。教員・講師の塾講師ロールのみOwner確認済み、ほかは叩き台のβ版）
2. 役割を選ぶ（業種によっては省略）
3. 週の勤務時間を入力
4. やっている業務にチェック（業種の業務＋全業種共通の業務）
5. チェックした業務ごとに「週あたりの時間・つらさ」を回答
6. 「ややつらい」「つらい」と答えた業務だけ、共通の理由リスト（同じ内容を何度も書く／手順が面倒／調整が大変／判断が難しい／人への対応がしんどい／体力的にきつい／量が多い／時間外にやっている、＋その他自由記述）から複数選択
7. 結果：負荷が集中している理由とその傾向、負荷が大きい業務トップ5（選んだ理由つき）、理由別の内訳、時間外・二度手間に該当する業務一覧、その他の自由記述、業務量が勤務時間を超えていないか、を表示

業務ごとの`tag`は診断の判定には使わず、業種データを作るときのバランス確認用に残している。判定ロジック・理由リスト・v2.1集計の詳細は [v2-spec.md](v2-spec.md) を参照。

## ファイル構成

- `index.html`：個人診断
- `aggregate.html`：職場集計（v2.1）
- `data/industries.js`：14業種の業務データ、`DATA_VERSION`（結果コードの互換性チェック用）
- `data/shared.js`：個人診断・職場集計の両方で使う共通定義（理由リスト・結果コードのエンコード/デコードなど）
- `styles.css`：両画面共通のスタイル
- `task-lists/`：業種ごとの業務リストの元データ（md）

## 動作検証

`test-flow.js`（puppeteer-core、ローカルChrome）で13シナリオを自動テスト済み（全PASS）。
- 「同じ内容を何度も書く」「人への対応がしんどい」それぞれが最大になるケースでメインメッセージが切り替わること
- 対人が最大でも定型・調整が2割以上あれば補足が出ること
- 「時間内に終わらず時間外」「同じ内容を何度も書く」を選んだ業務が結果に一覧で出ること
- 1つの業務で複数の理由を選んだとき、スコアが理由の数で按分されること
- 「あまりつらくない」を選んだ業務は理由選択画面がスキップされること
- 業務の合計時間が勤務時間を超えると注記が出ること
- 管理職限定の業務がスタッフ選択時に表示されないこと
- 全業種で共通業務が表示されること
- 役割ごとにカテゴリが丸ごと切り替わる業種（医師：研修医／勤務医／管理職）で、選んだ役割以外の業務が出ないこと
- 職場集計：5人分未満では結果が出ず、5人分そろうと出ること
- 職場集計：改善候補ランキングが優先度スコアの高い順に並ぶこと
- 結果コードに自由記述・勤務時間の具体的な数字が含まれないこと
- 職場集計：業種違い・古い版・壊れたコード・重複コードが件数付きで除外されること
