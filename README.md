# ①診断チェッカー（仮称）

`products/shindan-framework.md`のStage 1-2をインタラクティブなフォームにした軽量ツール。②（逆算学習計画メーカー）と同じ「無料・AI不使用・静的サイト・APIコスト0円」の型。

## 経緯

`products/shindan-checker-spec.md`（9/23作成）の仕様をこのタブでそのまま実装。当初は10月に別タブへ実装依頼する予定だったが、前倒しでこのタブ内で完結させた。

## 仕組み

- **Stage 1（症状の把握）**：誰が困っているか・症状の種類・いつから・自由記述を入力（この段階の回答は判定ロジックには使わず、ヒアリング時の思考整理用）
- **Stage 2（原因の切り分け）**：5つの質問（A業務量／B業務プロセス／C人員配置／D感情労働／E価値観のギャップ）に3段階で回答
- **判定ロジック**：B+Cのスコア合計とD+Eのスコア合計を比較し、①のサービス対象かどうかを判定。拮抗する場合は「詳しいヒアリングが必要」と表示
- 免責文言（「専門的な診断に代わるものではない」）を結果画面に表示

## 動作検証

`test-flow.js`（puppeteer-core、ローカルChrome）で3パターン（B/C優勢、D/E優勢、拮抗）を自動テスト済み。全パターンで想定通りのメッセージが表示されることを確認。
