# ①診断チェッカー（仮称）

自分の業種・業務を選ぶだけで、職場の負荷がどこに集中しているか（定型／調整／判断／対人／身体）がわかる簡易診断ツール。②（逆算学習計画メーカー）と同じ「無料・AI不使用・静的サイト・APIコスト0円」の型。

## v2の仕組み

1. 業種を選ぶ（14業種、[task-lists/](task-lists/)。教員・講師の塾講師ロールのみOwner確認済み、ほかは叩き台のβ版）
2. 役割を選ぶ（業種によっては省略）
3. 週の勤務時間を入力
4. やっている業務にチェック（業種の業務＋全業種共通の業務）
5. チェックした業務ごとに「週あたりの時間・つらさ・時間外にやるか・二度手間か」を回答
6. 結果：負荷が集中しているタグとその理由、負荷が大きい業務トップ5、タグ別の内訳、時間外・二度手間の業務一覧、業務量が勤務時間を超えていないか、を表示

判定ロジック・データ構造の詳細は [v2-spec.md](v2-spec.md) を参照。

## 動作検証

`test-flow.js`（puppeteer-core、ローカルChrome）で7シナリオを自動テスト済み（全PASS）。
- 定型／対人それぞれが最大になるケースでメインメッセージが切り替わること
- 対人が最大でも定型・調整が2割以上あれば補足が出ること
- 時間外・二度手間にチェックした業務が結果に一覧で出ること
- 業務の合計時間が勤務時間を超えると注記が出ること
- 管理職限定の業務がスタッフ選択時に表示されないこと
- 全業種で共通業務が表示されること
- 役割ごとにカテゴリが丸ごと切り替わる業種（医師：研修医／勤務医／管理職）で、選んだ役割以外の業務が出ないこと
